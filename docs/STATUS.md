## Índice Fatia ↔ SPEC (de-para canônico)

> **Por que dois números** — `Fatia N` é unidade de trabalho (pode ser fatiada em 7.5/7.6/7.7 depois); `SPEC-NNN` é ID de documento, imutável e em ordem de criação. Eles **divergem de propósito** e não devem ser reconciliados.

- **`[MVP3][SPEC-029][FIX]` Link de briefing não podia ser copiado de novo (#151)** — **entregue 2026-07-27, aguardando aceite.** Achado no dogfooding do PI: com o link já enviado, reabrir *Link de briefing* mostrava só *"Link já existe para este projeto"* e o botão *Regenerar* — **nenhuma URL na tela**.
